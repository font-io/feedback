# font.io feedback

Data corrections and improvement suggestions for [font.io](https://font.io),
the font reference.

Most issues here are filed automatically by the **Suggest an improvement**
form on font.io font and designer pages (they carry the `from-site` label).
You can also open one directly with the data correction template.

Every report is checked against primary sources before any data changes.
An issue closes when the correction is live, or with a note explaining
what the sources support.

For licensing or rights concerns, do not file a public issue here.
